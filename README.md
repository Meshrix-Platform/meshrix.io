# meshrix.io

Website for the Meshrix platform: [Meshrix.js](https://github.com/Meshrix-Platform/Meshrix.js), an open-source gateway and governance platform for agent tooling, and [Pactium](https://github.com/Meshrix-Platform/Pactium), its cryptographic proof substrate. Both packages are published on npm under Apache-2.0.

## Structure

```text
meshrix.io/
├── index.html                         # Landing page (platform + proof substrate)
├── styles.css                         # Dark terminal design system
├── CNAME                              # GitHub Pages custom domain
├── assets/
│   ├── favicon.svg                    # Meshrix.js gateway mark
│   ├── fonts/                         # Self-hosted variable fonts (Space Grotesk, JetBrains Mono; SIL OFL)
│   ├── console-workbench.png          # Web Console screenshots (4K, dark, EN)
│   ├── console-toolsets.png           #   tool catalog & permission groups
│   ├── console-upstreams.png          #   upstream services
│   └── console-approvals.png          #   approval queue
├── dns/
│   └── cloudflare-github-pages.txt    # Cloudflare DNS records
└── docs/
    └── releases/                      # Continuous-site release metadata
```

Static HTML, CSS, and vanilla JS (clipboard copy, scroll reveal, marquee, and console carousel) with no build step. Fonts are self-hosted under `assets/fonts/` with no third-party font requests; npm version and license badges are served by shields.io.

## Local Preview

```bash
python3 -m http.server 8090
# Open http://localhost:8090
```

## Deployment

Published via GitHub Pages from the `main` branch root at <https://meshrix.io> (bound by [CNAME](CNAME)).

- Import DNS records from [dns/cloudflare-github-pages.txt](dns/cloudflare-github-pages.txt) as **DNS-only (unproxied)** so GitHub Pages can validate the custom domain and provision TLS certificates.
- Verify `meshrix.io` in the Meshrix-Platform GitHub Pages settings using the TXT record generated by GitHub. GitHub Pages automatically redirects `www.meshrix.io` to `meshrix.io`.

See [docs/releases/README.md](docs/releases/README.md) for the continuous-site release profile.
