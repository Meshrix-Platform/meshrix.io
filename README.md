# meshrix.io

Updated: 2026-10-05

Official website for the Meshrix platform: [Meshrix.js](https://github.com/Meshrix-Platform/Meshrix.js), the open-source platform for governed agent tooling, and [Pactium](https://github.com/Meshrix-Platform/Pactium), its proof-first protocol substrate. Both are published on npm; see each repository for its source license.

## Structure

```text
meshrix.io/
├── index.html                         # Single-page portal (platform + substrate)
├── styles.css                         # Dark terminal design system
├── CNAME                              # GitHub Pages custom domain
├── .lico-auditor/
│   └── policy.json                    # Audit policy: declared public reference domains
├── assets/
│   ├── favicon.svg                    # Meshrix.js gateway mark (from apps/console)
│   ├── fonts/                         # Self-hosted variable fonts (SIL OFL)
│   ├── console-workbench.png          # Real Console screenshots (4K, dark, EN)
│   ├── console-toolsets.png           #   tool catalog — permission groups
│   ├── console-upstreams.png          #   upstream services
│   └── console-approvals.png          #   approval gate
└── dns/
    └── cloudflare-github-pages.txt    # Cloudflare DNS import source
```

The page is hand-written static HTML/CSS with small vanilla JS helpers
(copy-to-clipboard, scroll-reveal, marquee, console carousel); there is no
build step. The console visuals are real screenshots of the Meshrix.js Web
Console (4K, dark, English), not mockups. npm version and license badges are
served by shields.io. Fonts (Space Grotesk, JetBrains Mono) are self-hosted
variable fonts under `assets/fonts/` (SIL Open Font License), so the page
makes no third-party font requests.

## Deployment

The source is configured for GitHub Pages from the `main` branch root and uses
<https://meshrix.io> as its intended canonical address. Repository
configuration alone does not prove current publication or availability.

The root `CNAME` file binds the Pages site to `meshrix.io`. Set `meshrix.io` as the custom domain in the repository's Pages settings and point the DNS records at GitHub Pages from the DNS provider. GitHub Pages redirects `www.meshrix.io` to the configured apex domain after both names resolve correctly.

The DNS import source is [dns/cloudflare-github-pages.txt](dns/cloudflare-github-pages.txt). All records must stay DNS-only (unproxied) for GitHub's domain check and certificate provisioning.

For takeover protection, verify `meshrix.io` in the Meshrix-Platform organization Pages settings and add the exact TXT record generated by GitHub. The verification token is intentionally not stored in this repository.

This site is continuously delivered and does not own a product version. Its
[release profile](docs/releases/README.md) records that boundary.
