;; meshrix.io — GitHub Pages records for Cloudflare BIND import.

;; Import: Cloudflare Dashboard → meshrix.io zone → DNS → Records → Import and Export.
;; The zone already exists in Cloudflare, so SOA and authoritative NS records
;; are intentionally omitted.
;;
;; After importing:
;;   1. Keep every record DNS-only (gray cloud, cf_tags=cf-proxied:false below).
;;      GitHub's domain check and certificate provisioning need unproxied records.
;;   2. GitHub repo Meshrix-Platform/meshrix.io → Settings → Pages → set the
;;      custom domain to "meshrix.io" and wait for the DNS check to pass.
;;   3. Enable "Enforce HTTPS" once the certificate is issued.
;;   4. Takeover protection: github.com/organizations/Meshrix-Platform/settings/pages
;;      → "Add a domain" → verify meshrix.io, then add the TXT record GitHub
;;      generates (host "_github-pages-challenge-Meshrix-Platform"). The token
;;      is intentionally not stored here.
